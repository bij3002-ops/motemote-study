# 10분 공부 플래너 (motemote-study)

모트모트(올클 · 텐미닛 플래너) 감성의 **개인용 공부 웹앱(PWA)**.
아이폰 Safari에서 열고 ‘홈 화면에 추가’하면 전체화면 앱처럼 쓸 수 있습니다.

- 라이브: https://bij3002-ops.github.io/motemote-study/
- 스택: Vite + React + TypeScript, 손으로 쓴 CSS (프레임워크·백엔드 없음)
- 저장: 브라우저 `localStorage` (서버 전송 없음) + JSON 백업/복원

## 기능

### 1. 타이머 (타이머 탭)
- **스톱워치**: 과목 선택 → 시작 / 일시정지 / 저장
- **뽀모도로**: 25·5 / 50·10 / 15·3 프리셋, 집중이 끝나면 알림음과 함께 휴식으로 자동 전환
- 새로고침·백그라운드 전환에도 `startedAt` 타임스탬프로 경과 시간이 정확합니다
- Screen Wake Lock API로 타이머 중 화면 꺼짐 방지(지원 브라우저)
- **저장하면 그 시간대가 10분 타임테이블에 과목 색으로 자동 기록**됩니다
- **흑백 집중 모드**: 타이머를 재는 동안 앱 전체가 흑백으로 바뀌어(0.65초 페이드) 도파민 자극을 줄입니다.
  일시정지·저장·초기화를 누르면 바로 원래 색으로 돌아오고, 뽀모도로 휴식 구간은 컬러로 풀립니다.
  타이머 카드 아래 미니 칩으로 지금 상태를 보거나 바로 끄고 켤 수 있어요(설정 탭에서도 토글, 기본값 켜짐).

### 2. 텐미닛 플래너 (플래너 탭)
- 날짜 이동(‹ › / 날짜 선택 / 오늘), 대표 D-Day 배지, 오늘의 한 줄 다짐
- 모트모트식 태스크 매니저: `○` 미완료 → `△` 진행중 → `✓` 완료 → `→` 내일로 이월 순환
  (이월 시 다음 날로 자동 복사 옵션, 설정 탭)
- 10분 타임테이블 05:00–04:00, 한 줄 60분 × 6칸
  - 타이머 기록 자동 색칠 + 손가락 터치/가로 드래그로 수동 색칠·지우개
  - 현재 시각 표시선

### 3. 노랭이 토익 단어장 (단어장 탭)
- 해커스 토익 **노랭이** Anki 덱에서 추출한 **5,101개 단어** (빈출 1,241 · 기초 837 · 800점 2,033 · 900점 990)
- 4개 파트 × **DAY 01~30**, DAY별 진행률 · 뜻/단어 가리기 · 안 외운 단어만 보기
- Web Speech API(`en-US`) 발음 듣기 (iOS Safari 대응), 즐겨찾기(★) · 외움 체크(✓)
- **카드**: 선택 DAY / 파트 전체 / 즐겨찾기 / 오답을 섞어서 뒤집어 보기, 모르겠음은 뒤에 다시
- **퀴즈**: 범위 + 10·20·30문항, 영단어 → 뜻 4지선다, 틀린 단어는 오답노트에 자동 저장
- **검색·오답**: 5,101개 영단어/뜻 실시간 검색, 전체·파트별 달성률, 즐겨찾기·오답 모아보기
- 학습 기록은 `localStorage`에 저장되고 설정 탭 JSON 백업에 함께 담깁니다
- 단어 데이터(`public/data/noraengi-words.json`, 212KB)는 **단어장 탭을 처음 누를 때만** 내려받아 타이머·플래너 초기 로딩을 해치지 않습니다

### 4. 기출 CBT (기출 탭)
- **품질경영기사 · 정보처리기사 필기 최신 공개 기출 5회차씩 총 1,000문항**(각 100문항 · 5과목 × 20문항)
  - 품질경영기사: 2022-2 · 2022-1 · 2021-4 · 2021-2 · 2021-1
  - 정보처리기사: 2022-2 · 2022-1 · 2021-3 · 2021-2 · 2021-1 (해설집 공개분 포함)
- **실전 모의고사**: 회차 100문항 또는 과목별 20문항, 150분 타이머 · 문제 번호 점프 그리드 · 경과/남은 시간
  - 제출하면 **과목별 점수 · 과락(40점 미만) · 평균 60점 합격/불합격** 판정
  - 풀다가 다른 탭에 다녀와도 답안이 남아 있어요(이어서 풀기)
- **바로 풀기**: 문항을 고르면 즉시 정답/오답 표시 + 해설(정보처리기사 5회차)
- **오답노트 · 별표**: 틀린 문제 자동 저장, 별표 북마크, 회차별로 모아 다시 풀기
- **수식 · 관리도 · 표 · 코드 문제는 PDF에서 이미지로 잘라** 넣어 깨지지 않습니다
  (`public/data/cbt-img/{exam}/{round}/q{n}.webp`, 회차당 24~41문항)
- 회차 데이터는 `public/data/cbt/{exam}-{round}.json`으로 분리해 **해당 회차를 고를 때만** 내려받습니다
- 응시 이력·오답·별표는 `localStorage` 키 `motemote-study:cbt:v1`, 설정 탭 JSON 백업에 `cbt`로 함께 담깁니다

### 5. 통계 (통계 탭)
- 오늘 / 이번 주 / 이번 달 누적, 최근 7일 막대그래프
- 과목별 비율(스택 바 + 범례), 월간 공부 히트맵(월 이동)

### 6. D-Day · 설정 (설정 탭)
- D-Day 추가·수정·삭제 (기본값: 제82회 한능검 접수 2027-01-12, 정기기사 1회 필기 접수 2027-01-18, 정기기사 1회 필기 시작 2027-02-12)
- 과목 추가·이름/색 변경·삭제 (기본: 품질경영기사 · 산업안전기사 · 토익/오픽 · 학교 전공·팀플 · 한국사)
- 라이트 / 다크 / 시스템 테마
- 타이머 실행 시 흑백 집중 모드 (기본 켜짐)
- JSON 내보내기·불러오기(단어장 · 기출 CBT 기록 포함), 어제 하루 예시 채우기, 전체 초기화

## 개발

```bash
export PATH="$HOME/.tools/node-v24.22.3-linux-x64/bin:$PATH"
npm install
npm run dev        # http://localhost:5173
npm run typecheck  # tsc --noEmit
npm run build      # docs/ 로 정적 빌드 (GitHub Pages 소스)
```

아이콘 재생성: `python3 tools/generate_icons.py`
단어 데이터 재추출: `python3 tools/extract-noraengi.py` (원본 Anki 덱 → `public/data/noraengi-words.json`)
기출 CBT 데이터 재생성: 원본 PDF → `work/cbt/build_all.py` (PyMuPDF로 문항·정답·해설 파싱 + 수식/도표 크롭 → `public/data/cbt/`)

## 배포

`main` 브랜치의 `docs/` 폴더를 GitHub Pages 소스로 사용합니다.
빌드 결과물이 `docs/`에 들어가므로 `npm run build` 후 커밋·푸시하면 바로 반영됩니다.
`vite.config.ts`의 `base: './'` 덕분에 저장소 하위 경로(`/motemote-study/`)에서도 자산 경로가 맞습니다.

## 데이터 구조

```ts
AppData {
  subjects: { id, name, color }[]
  ddays:    { id, title, date }[]
  sessions: { id, subjectId, start, end }[]        // 타이머 기록(epoch ms)
  days:     Record<'YYYY-MM-DD', { tasks, memo, marks }>
  settings: { theme, wakeLock, autoCarry }
  timer:    { subjectId, mode, startedAt, accumulated, phase, focusMin, breakMin } | null
}
```

플래너의 하루는 새벽 05:00에 시작해 다음날 04:59에 끝나며, 통계도 같은 기준으로 집계합니다.
